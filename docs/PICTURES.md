# Pictures

Every picture on this site was made for HOLYDJO-CLEAN. No Oboosho photograph, illustration,
person, logo or text is used.

The scene photographs are new, art-directed images generated for this remake with an open
text-to-image model, then cropped and colour-graded for the slot and the blue and black brand. The brief supplied no photo
folder, so these are stand-ins for the real team and client photography. Replace a file with a
real photograph at the same path and aspect ratio and the layout will hold.

All files were generated for this project, cropped to remove the generator mark,
and saved as progressive JPEG. None contains text, a logo or a recognisable person’s face.

The mascot, logo, feature icons and team avatars are original vector drawings in
`src/illustrations.js`. The avatars are illustrations, not photographs of real staff; replace
them with real headshots before launch.
